# JeffMod
This mod adds many Jeff-related features to the game!

### Healing Bubble ![A healing bubble](https://cdn.modrinth.com/data/cached_images/451c697c849e241ce801204826e294fcf4a5f092.png)
Jeff's most iconic ability is being able to throw healing bubbles at allies, to speed them up and heal them.
> In this mod, throwing a healing bubble at an entity grants them **Speed 2** and **Regneration 2** for 10 seconds, as well as **Instant Health**.

### Pacifist (enchantment)
![Pacifist enchantment](https://cdn.modrinth.com/data/cached_images/3cbe88c0e231fc9ed11b38f7c1173fefa9305f4a.png)

Jeff doesn't like to hurt people. That's why, in this mod, there is an enchantment that heals rather than hurts
> This enchantment converts all damage to healing. It can be applied to all weapons.

### Purified (potion effect)
![Purification potion](https://cdn.modrinth.com/data/cached_images/1a7e59662e8714555202f5d758966424e3e36bd7_0.webp)

Jeff hates getting those annoying effects, like **Poison** and **Instant Damage**. This potion makes you immune to them.
> This potion effect makes it impossible for you to get any harmful potion effect.
